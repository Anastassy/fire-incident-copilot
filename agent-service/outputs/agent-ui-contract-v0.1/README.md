# Agent → UI · пакет передачи v0.1

12 сентября 2026. **Предлагаемый контракт, не работающая поставка API.** Описанные `/agent/v1/*` методы ещё не реализованы. Пакет можно использовать для параллельной разработки UI на JSON-примерах. Примеры синтетические; таймкоды иллюстрируют выбранный эпизод, но не подтверждают содержание реальной записи. Аудиофайлы не включены.

## Ответственность

Наш сервис управляет агентной частью: выполняет запросы, формирует утверждения, определяет результат проверки, создаёт и обновляет карточки, связывает доказательства. UI отображает полученное, передаёт вопросы и отмену, открывает источники. UI не выводит подтверждение из текста и не присваивает статус гипотезе самостоятельно.

Data Platform остаётся хранилищем исходных записей и incidents. Наш сервис хранит рабочий прогресс и связывает `hypothesis_id` с `platform_incident_id`. UI получает агентные карточки только от нашего сервиса, не объединяет их самостоятельно с платформенными incidents. Публичный incident ещё не создан → platform_incident_id=null, publication_status=pending.

Решение пользователя имеет приоритет над пунктом mvp-scope/03_DELIVERY.md о запрете create_incident: incidents сохраняются в платформе. Обязательная severity остаётся техническим полем публикации и НЕ входит в UI-контракт. Макет, стили и расположение элементов принадлежат Насте. Генерация dashboard.spec не требуется.

## Состав

- `openapi.json`: методы и JSON Schema.
- `examples/`: запрос, состояния ответа/карточки, два доказательства, snapshot и SSE.
- `example-manifest.json`: соответствие примеров схемам.
- `INTEGRATION.md`: последовательность подключения, версии, ошибки, аудио.
- `ACCEPTANCE.md`: проверки интеграции и граница реализованного.
- `validation.json`: результат проверки JSON-примеров.

Передавать весь ZIP. Сообщений коллегам автоматически не отправляли.

## Минимальный экран

Вопрос с состоянием выполнения; ответ с источниками у каждого утверждения; одна обновляемая карточка; evidence viewer с исходной записью и аудио; явное обозначение машинного текста. Полный журнал исходных данных идёт из Data Platform и не подменяется агентным ответом. Для демо язык en, ru также предусмотрен. Отображение статических названий статусов локализует UI, тексты утверждений формирует сервер.
