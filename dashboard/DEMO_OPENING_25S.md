# Первые 25 секунд демо-видео — вводная

Обновлено по решению пользователя: только problem statement, обещание решения и переход. Полная симуляция создаётся отдельно после 00:25. Границы Palisades MVP не изменены.

Этот план заменяет прежнее вступление с Chevron и раскрытием аудиоподтверждения.

| Время | Смысл | Главная подпись |
|---|---|---|
| 0–4 с | Неразрешённый вопрос о предстоящем эпизоде | A channel was assigned. Was it acknowledged? |
| 4–10 с | Работа оператора поддержки командования: собрать понимание из радиообмена | Keeping track is the operator’s job. |
| 10–15 с | Различие назначения, подтверждения и выполнения | Assigned → Acknowledged → Carried out? |
| 15–21 с | Обещание подхода, без показа результата | Track the exchange. Check the evidence. |
| 21–25 с | Переход к будущему Palisades replay | Was the assignment acknowledged? |

Графический UI постоянно помечен `Illustrative prototype · recorded radio`. Журнал ограничен историей до 02:10.420 focus, без будущих реплик. Хук — редакционный вопрос, не утверждение о текущем состоянии replay. Финал: пауза на 02:10.420, без чёрного экрана. Назначение, подтверждающая реплика, обновление карточки, ответ и открытие аудио остаются для основной симуляции.

Вводная содержит только дикторскую речь; радио не проигрывается. Источник текста — локальный машинный ASR, его непроверенный статус и атрибуция сохраняются. Chevron и температурные числа исключены. Эффективность и готовность интеграции не заявляются на основании иллюстративных кадров.
