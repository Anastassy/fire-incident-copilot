# Приёмка и задачи интеграции

Готовность компонентов — [IMPLEMENTATION_STATUS](../../IMPLEMENTATION_STATUS.md). Предыдущие выполненные тесты — [live/VALIDATION](../../live/VALIDATION.md).

До записи основного MVP:

1. Выбрать конкретный Base2 run и составить cue sheet с evidence IDs/временем по всем типам источников.
2. Согласовать State run/generation, platform IDs/scope и agent context.
3. Показать автоматическую проверку нескольких источников и вопрос с реальными queries/coverage.
4. Проверить доступ к измерению, событию связи, access, видео и аудио; не подменять missing.
5. Пройти отрицательные случаи: null occupancy, отсутствие passage, старый кадр, отключённый датчик, радио другого инцидента, ошибка, reset.
6. Отделить исходные данные, выводы и действие оператора. Не публиковать вымышленные метрики эффективности.

Channel reducer и синтетические Demo-кнопки не закрывают пункт 3. Назначение исполнителей — командное решение; этот документ не назначает новых владельцев автоматически.
