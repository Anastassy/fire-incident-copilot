# Тайминг демонстрации

120 секунд: 0–15 проблема, 15–25 подход, 25–90 основной многоканальный показ, 90–105 фактическая архитектура, 105–120 измеренный результат либо план пилота.

[Сценарий на 65 секунд](../../MVP_SCENARIO.md) заменяет старый основной показ только V-Fire 25. Вступление объясняет весь продукт и не раскрывает заранее вывод сцены.

Секунды ролика не равны времени State run. Перед seek/reset нужно согласовать generation. Для аудио — 1×; в ускоренном replay live UI приостанавливает звук. Не перекрывать исходное аудио диктором.

Готовые старые видео не переписываются этим обновлением документов; их соответствие новому сценарию требуется проверить перед подачей.
