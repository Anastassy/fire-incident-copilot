# Интерфейс оператора

Актуальная реализация — [Firewatch](../../live/README.md), dashboard/live. Тёмный рабочий экран с двумя CCTV, источниками/метриками, полным опубликованным журналом, радио и областью агента. Поддерживаются неизвестные/устаревшие/отключённые источники.

Основная задача — [многоканальный сценарий](../../MVP_SCENARIO.md). Оператор видит изменение, открывает источники, задаёт вопрос, проверяет ответ и докладывает руководителю. Приоритет — совпадение run/generation и происхождения, а не визуальное объединение несовместимых событий.

Предыдущие V1–V4 сохранены в docs/design. Они демонстрируют радио и не задают текущий scope. Реальный UI API не означает, что FixtureEngine анализирует текущий State run.
