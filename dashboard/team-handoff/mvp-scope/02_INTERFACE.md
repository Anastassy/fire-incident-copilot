## Обновление V3

Актуален интерактивный сценарий «Did the group get an answer?»: запрос → ответ → подтверждающая реплика, с промежуточной проверкой на каждом новом сообщении. Макет: `docs/design/palisades-console.html`; сценарий на 65 секунд и точки подключения data/replay/agent/media: `docs/design/palisades/README.md`, типы `ports.d.ts`. Подключение к уже добавленному agent-service требует адаптера: [сверка с main](../../docs/design/palisades/BACKEND_COMPATIBILITY.md). Серверный контракт сохранён.

## Предыдущая версия V2 — заменена V3 выше


Desktop 1440×900, английский UI, роль — информационная поддержка командования. На первом экране один крупный результат проверки: V-Fire 25 и состояние ответной реплики, основная кнопка Listen to reply. Две ссылки на основания и видимое ограничение: переход всех участников не доказан. Это состояние после появления соответствующих данных, не стартовое утверждение.

Полный журнал с поиском открывается постоянной кнопкой со счётчиком; Ask Copilot — по действию; одна последняя реплика под результатом. Управление ведущего свёрнуто. Исходный канал — архив V-1; V-Fire 25 только упомянут в записи. Макет содержит подготовленные состояния, а не подключённую модель/платформу.

[Актуальный HTML](../../docs/design/palisades-console.html). В рабочем приложении результат формирует агентный сервис по [контракту](../../../agent-ui-contract-v0.1/README.md); UI не определяет подтверждение самостоятельно по тексту или таймкоду.

Общие три элемента:

1. Ответ с источниками рядом с каждым утверждением, кнопка перехода к записи. Раздельно — известное, гипотезы, неизвестное. Стадии показывают реальные вызовы инструментов, не вымышленное рассуждение.
2. Одна фоновая карточка с устойчивым ID и revision; статусы: проверяется / поддержана / опровергнута / недостаточно данных. Новая информация обновляет её.
3. Панель доказательства сохраняет контекст, открывает соответствующую запись; закрытие возвращает фокус на ссылку. Отсутствующий файл или запись показываются честно.

Оператор выбирает объект, задаёт вопрос, открывает основание, уточняет и вручную фильтрует журнал. Может скопировать ответ со ссылками; приложение ничего не отправляет команде. Управление replay — отдельные элементы ведущего демо.

Обязательные состояния ответа: ожидание, выполнение, готов, недостаточно данных, ошибка, отменён. Ошибка поиска не равна отсутствию подтверждения. При разрыве сети данные остаются с отметкой последнего обновления; при новом прогоне старые ответы и плееры отменяются. Пауза сценария не означает потерю сети.

Для Palisades: готовый ASR обозначен prerecorded, machine-generated, not human verified. Ссылки ведут к опубликованному аудио. Смещение focus к полному WAV — 292 секунды; offset AAC берётся из metadata (в описанной поставке 64 ms), это разные шкалы.

## Взаимодействие с руководителем в демонстрации

Руководитель (роль участника хакатона): «Какой канал назначили Coastline? Есть ответ?» Оператор задаёт вопрос Copilot, открывает два основания и прослушивает. После проверки говорит руководителю: «В записи назначен V-Fire 25; есть подтверждающая реплика. Переход всех участников этим не подтверждён».

Это ролевая сцена, помеченная отдельно от исторического радио. Архивные реплики не являются ответом на клики/голос участника демо и не меняются. Prepare briefing создаёт черновик, не отправляет сообщение. PTT и радиопередачи не входят в MVP.

Ориентир финального видео: 120 секунд, живой показ — 0:25–1:30 (65 секунд). Подробный [тайминг](04_VIDEO_TIMING.md) заменяет прежний 90-секундный план. Перед началом опубликована история до 02:10.420; ответы из будущего отсутствуют. Это не SLA.

Интеграционные проверки и ручная точность ASR не подтверждены просмотром макета.
