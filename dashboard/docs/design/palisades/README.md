# Palisades V3: интерактивный макет

Открыть `../palisades-console.html` в браузере. Сборка и npm не нужны; аудио поставляется вместе с `data/demo/palisades-radio-demo`. Для локального HTTP: из корня проекта `python3 -m http.server 8766 --bind 127.0.0.1`.

## Что происходит во времени

| Время focus | Новые данные | Карточка Copilot после проверки |
|---|---|---|
| 02:10.420, старт на паузе | Запрос опубликован | Answer not found yet |
| 02:15.760 | Закончилось назначение канала | Answer found; V-Fire 25 в пояснении |
| 02:20.260 | Опубликована подтверждающая реплика | Confirming reply found |
| 02:22 | Конец короткого replay | Результат остаётся доступен |

После каждой новой реплики отдельно показывается Checking. Задержка 650 мс — искусственная анимация мока, не замер производительности. Публикация сегмента происходит по его окончании. История и ответы используют только опубликованную часть. Запрос, назначение и подтверждающая реплика связаны сценарием; личности говорящих не установлены, переход всех участников не доказан.

Start / resume запускает текстовый replay 1×; аудио слушается по кнопке Listen. Открытие доказательства ставит replay на паузу. Restart сбрасывает время, вопросы, результаты и проигрывание. Это управление архивным демо, не остановка реального инцидента.

Оператор наблюдает изменение карточки, слушает первоисточник, спрашивает «все ли перешли?», получает ограниченный доказательствами ответ и готовит черновик доклада. Доклад можно скопировать; отправки в радио нет. Разговор оператора с руководителем разыгрывается отдельно и помечается как ролевая сцена.

## Показ внутри 65 секунд основного демо

- 0–8: показать запрос без ответа, объяснить роль оператора.
- 8–20: Start replay; новая реплика → проверка → ответ → подтверждающая реплика.
- 20–32: Listen to reply, проверить оригинал.
- 32–48: Ask Copilot → вопрос о переходе всех участников; показать предел вывода.
- 48–60: черновик доклада, оператор устно сообщает руководителю результат.
- 60–65: кратко закрепить ценность: найден ответ, показан источник, сохранена неопределённость.

Это 25–90-я секунды общего двухминутного видео; вводная остаётся без раскрытия ответа.

## Точки подключения

`app.js` рисует экран и работает через `window.PalisadesAdapters`. Сейчас объект создаётся фабрикой из `mock-adapters.js`; `fixtures.js` содержит подготовленную ASR-историю. Для интеграции задайте `window.PalisadesAdapters` перед загрузкой `app.js`; скрипты fixtures/mock можно убрать. Типы — `ports.d.ts`. Это внутренний UI-контракт, а не новая версия серверных контрактов проекта.

| Порт | Куда подключить | Зависимые части экрана |
|---|---|---|
| data | Адаптер опубликованных записей Data Platform | Время, последняя реплика, журнал, поиск, источники |
| replay | Адаптер виртуального времени StateMachine | Start, pause, restart, прогресс |
| agent | Серверный Copilot, фоновые проверки и вопросы | Карточка, состояние проверки, ответ, черновик |
| media | Разрешение ID записи в аудио и интервал | Модальное окно и плеер |

Данные нормализуются на границе адаптера. `mock-radio-*` — локальные ID, не platform reading_id. Сохраните настоящие ID, происхождение, временную шкалу и ссылки на источники. Секреты и вызовы модели остаются на сервере. При reset увеличивайте generation: результаты прежнего запуска отбрасываются. Любой getRecord/history должен исключать будущее. Полные fixtures допустимы только в локальном макете; производственный клиент не должен получать будущую историю.

Data Platform, модель и серверные адаптеры пока не подключены. Свободный вопрос в мок-режиме поддерживает только подготовленные темы; это явно обозначено. Технологии ребят подключаются через порты без переписывания разметки.

## Проверки и ограничения

Demo checks раскрывает контрольный запуск с удалённой подтверждающей репликой и имитацию ошибки/retry. Контрольный запуск помечен на экране; это изменённые входные данные, не исторический факт. Сам архивный аудиофайл при этом не изменяется. Ошибка агента отличается от результата «не найдено»; опубликованные источники остаются доступны. Запросы и аудио защищены от запоздалых результатов после reset; устаревший ответ помечается временем.

`node dashboard/docs/design/palisades/mock-adapters.test.cjs` проверяет границу публикации, последовательность стадий, отсутствие подтверждения, недоступность будущих источников, reset во время вопроса, error/retry и pause. Проверка не подтверждает точность машинной транскрипции.
