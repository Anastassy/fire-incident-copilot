# Материалы для первого Git-коммита

Добавляем непосредственно в Git выбранные исходники. Дальнейшие изменения — через commit, push и PR, без сборки ZIP и без Python-экспорта.

| Добавить | Зачем |
| --- | --- |
| README.md | Публичное описание проблемы, решения, демо, запуска и текущей готовности |
| CONTRIBUTING.md, AGENTS.md, PROJECT_CONTEXT.md, docs/team/ | Рабочий процесс и контекст для участников |
| team-handoff/mvp-scope/ | Актуальные границы MVP и приёмка, включая уточнения тайминга видео |
| PALISADES_INTERFACE_SPEC.md, docs/design/palisades-console.html | Спецификация и текущий макет |
| docs/contracts/ | Контракты сервисов; старый v0.2 явно исторический |
| data/demo/ | Аудио, ASR, происхождение, лицензия и контрольные суммы |
| DEMO_OPENING_25S.md, CREATE_DEMO_VIDEO_CODEX_PROMPT.md, RUN_DEMO_VIDEO.md | Подготовка вступления; не готовый продуктовый ролик |
| DEMO_EVIDENCE_BANK.md, MVP_EVIDENCE_REASSESSMENT.md | Основания проблематики и выбора сценария |
| .gitignore | Исключения локальных и временных файлов |

Небольшие исторические Markdown и схемы, на которые ссылается PROJECT_CONTEXT, можно сохранить для прослеживаемости решений. Они не расширяют актуальный MVP. Полные 10 минут аудио оставлены вместе с focus (около 34 МБ всего пакета): сохраняются проверяемые исходные таймкоды и manifest. Машинный текст не является вручную проверенным или live-ASR.

Не добавлять: team-handoff/github-export/, scripts/export_team_package.py, scripts/team-package.json, старые ZIP, tmp/, временные output/, .DS_Store, .env, ключи и зависимости. Исследовательские PDF и случайные скриншоты не нужны для старта приложения. Перед коммитом просмотреть `git diff --cached` и список выбранных файлов; не использовать `git add .` для всей исследовательской папки.

Старый экспорт больше не является актуальной поставкой. Новые материалы, включая код участников и исходники видео, добавляются обычными коммитами. Готовность интеграции и финального видео отражать в README по факту проверки.
