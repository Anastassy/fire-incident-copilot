# Интерфейс и действия оператора

## Обновление V3

Актуален интерактивный сценарий «Did the group get an answer?»: запрос → ответ → подтверждающая реплика, с промежуточной проверкой на каждом новом сообщении. Макет: `docs/design/palisades-console.html`; сценарий на 65 секунд и точки подключения data/replay/agent/media: `docs/design/palisades/README.md`, типы `ports.d.ts`. Это заменяет статические состояния и прежнюю компоновку ниже. Модель и платформа пока не подключены.


**V2 после исследования HMI и официальной рубрики:** нижеописанные две равные зоны заменены одним обзорным результатом. Крупно V-Fire 25 и состояние ответной реплики; основная кнопка Listen to reply. Две ссылки на основания и видимое ограничение про всех участников. Полный журнал с поиском — по постоянной кнопке; Ask Copilot раскрывается по действию; одна последняя реплика под результатом. Scope и запрет автоматической передачи сохранены. Это актуальная компоновка, предыдущие детали ниже — история решения.

Официальная оценка: 4 критерия по 1–5 — работающий агент, новизна/контекст среды, техническая интеграция, полезность и контроль человека. Процентные веса не опубликованы. Видео — 2 минуты. Красивый макет без живых запросов не закрывает работоспособность/интеграцию. Исследования находятся в основном проекте: docs/research/CRITICAL_INTERFACE_RESEARCH.md и HACKATHON_CRITERIA_RESEARCH.md.


Один desktop-браузер, целевой размер 1440×900, английский демонстрационный интерфейс. Пользователь демо — сотрудник информационной поддержки командования, проверяющий радиообмен. Это демонстрационная роль, не идентификация участника записи.

Уточнение после запроса пользователя уменьшить текстовую нагрузку: **две рабочие зоны**, вместо прежних трёх колонок.

| Область | Текущий Palisades-экран |
| --- | --- |
| Шапка | Palisades · 7 Jan 2025 · Recorded replay; часы; статус подключения |
| Слева ≈50% | Радиоканал V-1, три последних опубликованных фразы, кнопки аудио, счётчик и доступ ко всей истории/поиску |
| Справа ≈50% | Copilot: одна цепочка запрос → назначение → подтверждающая реплика; одна строка результата; контекстные вопросы |
| По запросу | Короткий ответ с источниками, панель доказательства, подробности проверки и черновик доклада |

Исходное радио не переключается на V-Fire 25: это канал, упомянутый в записи, а доступный источник — архив V-1. Точный исторический интерфейс Palisades неизвестен; базовая консоль — наш проектный baseline.

Стартовый экран: три реплики и одна проверка. Ответ — 1–2 предложения. JSON, история проверок и полная расшифровка раскрываются отдельно. Визуальный радио-макет подготовлен в основном проекте (`docs/design/palisades-console.html`), но это подготовленные состояния без модели и платформы. `archive/room-layout.svg` — историческая серверная.

Общие три элемента:

1. Ответ с источниками рядом с каждым утверждением, кнопка перехода к записи. Раздельно — известное, гипотезы, неизвестное. Стадии показывают реальные вызовы инструментов, не вымышленное рассуждение.
2. Одна фоновая карточка с устойчивым ID и revision; статусы: проверяется / поддержана / опровергнута / недостаточно данных. Новая информация обновляет её.
3. Панель доказательства сохраняет контекст, открывает соответствующую запись; закрытие возвращает фокус на ссылку. Отсутствующий файл или запись показываются честно.

Оператор выбирает объект, задаёт вопрос, открывает основание, уточняет и вручную фильтрует журнал. Может скопировать ответ со ссылками; приложение ничего не отправляет команде. Управление replay — отдельные элементы ведущего демо.

Обязательные состояния ответа: ожидание, выполнение, готов, недостаточно данных, ошибка, отменён. Ошибка поиска не равна отсутствию подтверждения. При разрыве сети данные остаются с отметкой последнего обновления; при новом прогоне старые ответы и плееры отменяются. Пауза сценария не означает потерю сети.

Для Palisades: готовый ASR обозначен prerecorded, machine-generated, not human verified. Ссылки ведут к опубликованному аудио. Смещение focus к полному WAV — 292 секунды; offset AAC берётся из metadata (в описанной поставке 64 ms), это разные шкалы.

## Взаимодействие с руководителем в демонстрации

Руководитель (роль участника хакатона): «Какой канал назначили Coastline? Есть ответ?» Оператор задаёт вопрос Copilot, открывает два основания и прослушивает. После проверки говорит руководителю: «В записи назначен V-Fire 25; есть подтверждающая реплика. Переход всех участников этим не подтверждён».

Это ролевая сцена, помеченная отдельно от исторического радио. Архивные реплики не являются ответом на клики/голос участника демо и не меняются. Prepare briefing создаёт черновик, не отправляет сообщение. PTT и радиопередачи не входят в MVP.

Ориентир финального видео: 120 секунд, живой показ — 0:25–1:30 (65 секунд). Подробный [тайминг](04_VIDEO_TIMING.md) заменяет прежний 90-секундный план. Перед началом опубликована история до 02:10.420; ответы из будущего отсутствуют. Это не SLA.

Полная спецификация в основном проекте: PALISADES_INTERFACE_SPEC.md. Интеграционные проверки и ручная точность ASR не подтверждены просмотром макета.
