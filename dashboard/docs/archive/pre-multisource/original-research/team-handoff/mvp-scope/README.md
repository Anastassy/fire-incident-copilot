# MVP scope — пакет для команды и Артёма

Срез решений: 12 сентября 2026. Папка автономна для обсуждения скоупа; исходные медиа, серверы и API-пакеты в неё не включены. Это спецификация, не поставка приложения.

**Главный MVP подтверждён пользователем: Palisades — радиообмен и подтверждение канала.** Сценарий `palisades-focus` (206 секунд), эпизод назначения V-Fire 25. Серверная снята с текущего скоупа и сохранена только в archive. Промышленный оперативный центр остаётся гипотезой первого рынка, а не местом записанного инцидента.

Обязательное ядро уже определено: один экран; вопросы с источниками возле утверждений; фоновая проверка; просмотр доказательств. Data Platform — источник данных, агент проверяет гипотезы и отвечает, не командует.

Основания внутри основного проекта: MVP_INTERFACE_DECISION.md — исходный выбор; MVP_EVIDENCE_REASSESSMENT.md — последняя рекомендация; DEMO_EVIDENCE_BANK.md — материал питча, не полномочие менять scope; State Machine 0.2.2 и Safety Telemetry Platform v1 — разные контракты; data/demo/palisades-radio-demo — аудио и непроверенный ASR.

Исследовательские ссылки и полные технические схемы остаются в основном проекте. Этот пакет не приписывает Артёму ещё не согласованную исполнительскую роль. Обновлять пакет при принятии решений; архив рядом — переносимый срез, его нужно пересобирать после изменений.

## Передача в общий репозиторий

Scope, текущий HTML, аудио и контракты добавляются напрямую в Git и обновляются через commit/push/PR. Список материалов — docs/team/PACKAGE.md в корне проекта; порядок совместной работы — CONTRIBUTING.md. Python-экспорт и ZIP не используются для синхронизации. Публичный README описывает решение, инструкции участников находятся отдельно. Скоуп и роли этим дополнением не изменены.
