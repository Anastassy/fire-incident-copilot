# Отдельный экземпляр на сервере

Примеры предназначены для нового экземпляра. У них отдельные имя unit,
каталог и порт `18787`; действующие сервисы и базы из этих файлов не настраиваются.
Само клонирование ветки ничего не разворачивает и не перезапускает.

1. Разместить содержимое `state-machine/` в `/opt/state-machine-demo`, установить
   Python 3.10+ и FFmpeg, создать системного пользователя `state-machine-demo`.
2. От его имени собрать bundle и конфигурацию:

```bash
cd /opt/state-machine-demo
python3 scripts/build_demo_bundle.py
python3 scripts/setup_local.py --public-url https://state-api.example.com/api/v1
```

3. Заменить пример домена на свой в конфигурации и Caddy. В `var/private/server.json`
   задать `extra_origins` как список точных адресов интерфейса, например
   `["https://ui.example.com"]`. Localhost разрешён по умолчанию; wildcard нет.
4. Проверить пользователя, права и пути в [unit](state-machine-demo.service.example).
   Установить его под новым именем `state-machine-demo.service` и запустить только этот unit.
5. Добавить отдельный site-блок [Caddy](Caddyfile.example) в конфигурацию своего прокси,
   проверить всю конфигурацию `caddy validate` и затем reload. При общем сервере
   сначала проверить занятые имена доменов/портов и существующие site-блоки.
6. Проверить `/api/v1/health`, auth, SSE и медиа по внешнему HTTPS-адресу.

Примеры не создают DNS, не управляют провайдерами и не содержат провайдерских токенов.
Клиенту выдаётся только application read/control token. Каждый `owner` изолирует runs;
для совместной работы UI и обработчик используют токены одного owner и один run_id.

SQLite и ключи лежат в `var/private/`, медиа — в отдельном bundle. Для резервной копии
работающей базы используйте SQLite backup API или `.backup`, а не копию одного файла
при активном WAL. Для обновления сохраняйте ключи, БД и использованный bundle:
версии входных сценариев проверяются при восстановлении. Новый несовместимый bundle
запускайте с новой БД; смена bundle не мигрирует сохранённый replay.

Путь `--package` импортёра радио должен указывать на пакет репозитория, если рядом с
`/opt/state-machine-demo` нет `data/demo/palisades-radio-demo`. Это необязательный шаг.
Linux/systemd и внешний TLS для этих шаблонов отдельно не разворачивались при публикации;
автоматические проверки запускают сервис локально.
