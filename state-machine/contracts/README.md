# Контракт State Machine v0.2 — сырые данные

Начните с [короткой инструкции клиенту](v0.2/CLIENT_FLOW.md).
Для локального или размещённого экземпляра — [адрес, доступ и подключение потоков](v0.2/CONNECTION.md).
Полный договор передачи данных — [v0.2/README.md](v0.2/README.md),
машиночитаемая спецификация — [v0.2/openapi.json](v0.2/openapi.json).

Этот пакет заменяет первоначальный State API v0.1. Он не заменяет отдельный
Agent → UI контракт в `agent-ui-contract-v0.1/`. Распознавание и аналитика относятся к
другому проекту. Здесь исходные данные, технические состояния и воспроизведение
готовой расшифровки из пользовательского пакета [Palisades](v0.2/PALISADES.md).

Версия документа 0.2.2, схема 0.2. Добавлены события radio_transcript из готового текста;
состояния передаются сервером через SSE. Инструкция подключения дополняет схемы.
Пакет содержит только документацию, схемы, инструменты проверки и вымышленные примеры.
Исходные датасеты, ключи и частные исследования в него не включены.

Генерация и проверка из этой папки:

```bash
python3 tools/build_contract.py
uv run --with jsonschema --with openapi-spec-validator python tools/validate_contract.py
```

`uv` устанавливает зависимости проверки в отдельное окружение; рабочему приложению
они не требуются. Генератор перезаписывает OpenAPI и examples, поэтому изменения
этих файлов следует вносить через `tools/build_contract.py`.
Результат проверки — [v0.2/validation.json](v0.2/validation.json).
