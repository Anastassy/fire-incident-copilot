# Изменения контракта

## 0.2.2 · 2026-09-12 · актуальная версия

По уточнению пользователя добавлен replay готовой расшифровки пакета Palisades
вместе с аудио. Observation.kind=radio_transcript, RadioTranscriptData, TranscriptWord,
опциональные RadioChannel.latest_transcript/transcript_delivery и capability
prerecorded_radio_transcripts. Сохраняются источник, машинное происхождение и таймкоды.
Сервер не выполняет ASR. Новые сценарии palisades-full/palisades-focus сохраняют
прежние сценарии и запуски. MediaStream.media_timestamp_offset_ms задаёт отображение
времени AAC в исходный WAV. Потоки ограничены устройствами конкретного сценария.

## 0.2.1 · 2026-09-12

Добавлены непрерывные HTTP-потоки fMP4 для видео и аудио: один GET на канал,
последующая передача фрагментов сервером по часам run. Основной поток состояний — SSE.
MediaStream/MediaStreamList и capability continuous_media дополняют сырой контракт.
Range-доступ к отдельным Media сохранён для истории. Историческая серверная выборка —
два видео и два аудиоисточника. Распознавание остаётся в другом проекте.

## 0.2.0-draft · 2026-09-12

Граница проекта уточнена: State Machine передаёт сырые данные; распознавание
и анализ выполняет внешний слой в другом проекте. Версия схемы теперь 0.2.

Удалены analysis_mode, транскрипции и их endpoints/события, очередь ASR,
CV-оценки, Context/Conclusion, интерпретация докладов, вычисленные уровни опасности
и оценки присутствия людей по косвенным сигналам. Радио передаёт аудио и метаданные.
Occupancy хранит только значение прямого источника people_count либо null.

Сохранены HTTP-команды, SSE, курсоры, generation, сырые показания, видео/аудио,
СКУД, происхождение и технические состояния. Обновлены OpenAPI и все примеры.

Это несовместимая переработка первоначального draft до реализации API.
Пакет v0.1 и его архив устарели; для интеграции использовать только v0.2.

## 0.1.0-draft · 2026-09-12 · заменена

Первоначальный вариант включал распознавание и аналитику в этом сервисе.
Такое распределение обязанностей отменено уточнением пользователя.

## Поставка в репозиторий

Схема 0.2 и документ 0.2.2 сохранены. OpenAPI использует относительный сервер
`/api/v1`. Инструкция подключения описывает независимые локальные ключи и
синтетические входы; импортёр использует существующий Palisades focus.
Содержимое размещённого экземпляра определяется его bundle, не этими примерами.
